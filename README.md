# SellerSprite Affiliate Discount Codes Website

A simple, responsive website that displays SellerSprite affiliate discount codes and usage instructions.

## Features

- Display of discount code "Duncan57" with 81% off monthly and 57% off annual basic plans
- Display of discount code "Duncan35" with 35% off other annual plans
- Clear instructions on how to apply the discount codes
- Responsive design that works on both desktop and mobile devices

## Local Development

To run this website locally:

1. Clone this repository
2. Open the `index.html` file in a web browser
3. No server setup required as this is a static website

## Structure

- `index.html` - Main webpage content
- `styles.css` - Stylesheet for the website
